# Лабораторная работа 3

Вариант 1. Amazon Reviews 2023, категория All_Beauty.

Сценарий: суточная витрина товара для рекомендательной системы.

Пайплайн ELT: проверка схемы, DLQ, идемпотентный ключ, SQL-модель витрины. Блокнот сам записывает проект dbt во временный каталог и запускает его, если пакет установлен. В GitHub Actions файл `.github/workflows/lab3_etl.yml` на Python 3.11 создаёт маленький DuckDB и выполняет `dbt run` этой модели.

Блокнот: `../лаб3.ipynb`.
Проект dbt: `../лаб3_dbt`.
